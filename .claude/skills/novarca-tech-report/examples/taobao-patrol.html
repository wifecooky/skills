AI の使いどころ

  • 動かすLLM なし

    巡回そのものはLLM なしで動く。今回は Claude Code がコマンドを実行したが、人が実行しても同じ

  • 読む端末内

    OCR（Vision・PaddleOCR）は Mac の中で動く文字認識モデル。画像を外部に送らない

  • まとめるAI あり

    CSV の整形とこのページの作成に Claude Code を使用。価格は人が抽査する

1 件あたりの処理（約 16 秒）

6 ステップ
  1. ホーム → Safari を開く3.2 秒
  2. アドレスバーを選択（cmd+L）1.0 秒
  3. taobao:// URL を入力（約 50 文字）約 3.5 秒
  4. 「開く」ダイアログを待って認識・タップ約 3.5 秒
  5. 淘宝の商品詳細ページの読み込み待ち4.5 秒
  6. スクショ＋Vision でブロック検知（スライダー認証・ログイン画面）約 0.5 秒
  • 待ち時間はスクリプトの固定値、入力と認識の時間は推定値
  • 固定の待ちは合計約 12 秒。画面の変化を検知して進めば約 10 秒に縮められる見込み（速度とブロックの関係は未検証）
  • PaddleOCR は別プロセスで動くため、この 16 秒には含まれない

未検証・次に確かめること

  • 規模：数百件を続けて巡回しても止まらないか
  • 期間：毎日動かしてもブロック・ログアウトが起きないか
  • 速さ：待ち時間を縮めた（約 10 秒／件）ときにブロックが増えないか
  • 精度：OCR の価格を全件、画面と照合して誤りの割合を出す
  • 再現性：別の iPhone・別のアカウントでも同じように動くか

  • iPhone の開発者モードは OFF のまま
  • 使い終わったら iPhoneUse を停止する
