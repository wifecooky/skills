# 功能地图（<项目名>）

每一行是一个用户能做的操作，和应该看到的结果。`node scripts/verify.mjs` 在 390px（手机）和 1440px（桌面）下逐条跑一遍，断言页面状态并截图。截图汇总在 `.verify/index.html`。

规则：
- 加功能或改交互时，先在这张表里加一行或改期望，再在 `scripts/verify.mjs` 的 `TESTS` 里写同名测试。两边的 id 对不上，verify 直接失败。
- 删功能时，两边一起删。
- 期望一栏写看得见、查得到的结果，不写「正常」「可用」。
- 数目和名单从页面上现读，加了内容不用改测试。
- 每个测试都要先在弄坏的代码上失败一次，才算数。

## 自动验收
