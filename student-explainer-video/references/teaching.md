# 教学编排

开场 = 一句定位 + 一个学生能在画面上判断的问题。定位句说清今天的对象，例如“今天的主角是直角三角形”；问题服务于解释，后续确实回答它。片名、署名由模板的片头承担，讲稿不念。一次视频聚焦一个核心关系，长度随信息密度和真实旁白确定；用户给出时长时优先压缩内容，不靠加速塞满。

口吻可以有好奇、意外和成就感。低龄内容可更形象；初高中内容保留尊重感。不要假定所有学生都喜欢同一种性别、童声或娱乐风格。

## 勾股定理示例

引导句（示意口吻用，讲稿按自己的内容重写）：“把这四块三角形挪一挪，空白部分的总面积会变大吗？先猜一下。看，外面的大正方形没变，四块三角形也一块没少。所以，剩下的空白，面积当然没变。勾股定理的秘密，就藏在这个没变里。”

这只是引导片段，完整证明还需解释空白为什么分别是 c² 与 a²+b²。

可验证的排布：令两直角边 a,b>0，外框边长 S=a+b。原始三角形顶点为 (0,0),(a,0),(0,b)。先用标准二维旋转公式旋转，再平移；SVG 的 y 轴向下，按实际坐标核对视觉方向。

| 状态 | 四块三角形的 (平移 x, 平移 y, 旋转角度) |
| --- | --- |
| 中间为斜边正方形 | (0,0,0°), (S,0,90°), (S,S,180°), (0,S,270°) |
| 空白分成两个正方形 | (0,a,0°), (S,0,90°), (a,S,180°), (a,a,270°) |

初态内四边形顶点为 (a,0),(S,a),(b,S),(0,b)。验证四边均为 c，且相邻向量垂直；终态空白是 [0,a]×[0,a] 与 [a,S]×[a,S]。外框面积不变，四个全等三角形总面积不变，所以 c²=a²+b²。运动过程的临时覆盖不用于证明面积等式。

先具体后一般：字母公式第一次出现之前，先用一组数字让学生亲眼看到它成立，例如 3、4、5 数格子，9 加 16 正好 25。实例证明不了一般结论，所以之后仍要给拼图证明；结尾再代入一次做检验。迁移题至少一个现实场景，例如梯子靠墙、屏幕对角线；换一组数字不算迁移。可再问“直角边是 5 和 12，斜边是多少？”答案 13，并说明只对直角三角形直接适用。

## 讲稿和画面配合

- 先出现对象，再说“这里”“这块”；避免代词指向还没显示的图形。
- 第一个答案出现之前最多一个问题；问题的答案在紧接着的场景里给出。
- 挪动、拆分、替换这类对比动画，把变化前的状态留在画面上：复制一份图形，在副本上做变化，原图变淡但不消失，两者并排直到对比句（“没变”“一样大”）说完。让学生用眼睛比，而不是靠记忆。
- 公式写 a²+b²=c²，配音文字写成可正确朗读的版本，例如“A 的平方，加 B 的平方，等于 C 的平方”。显示稿和朗读稿可分别保存。
- 提问后的思考停顿要进入成片时间线：在该场景的输入里写 `pauseAfter`，让 `narrate.py` 一并算进帧号和字幕。只在相应概念出现时高亮，避免字幕、公式和图形同时争夺注意。
- 结尾给一个能检验理解的小任务，避免只重复口号或请求点赞。
